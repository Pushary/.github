# Getting help

For an adapter or plugin problem, open an issue in the repository you installed from. Include the package and framework versions, runtime and operating system, the command you ran, and redacted expected and actual output. A small reproduction using a simulated answer helps us investigate without access to your customers.

Start with the [integration documentation](https://pushary.com/docs/agents/adapters). For account-specific support, use the support option in your Pushary dashboard.

Never post API keys, webhook secrets, private enrollment links, customer documents or saved agent state in a public issue. For security reports, follow the repository's security policy when one is provided.
